# 📊Pedestrian Traffic Analytics

Автоматизированная система интеллектуального анализа и подсчета пешеходного трафика для коммерческих точек (на примере оценки локации для стрит-фуда) с использованием компьютерного зрения.

Система решает проблему точной оценки входящего потока людей, отсекая машины и учитывая направление движения (транзит влево/вправо), что позволяет прогнозировать конверсию и будущую выручку торговой точки.

---

## ✨ Ключевые возможности

* **Двунаправленный горизонтальный подсчет:** Точно фиксирует пешеходов, пересекающих наклонный виртуальный коридор (`IN` / `OUT`).
* **Умная фильтрация объектов:** Благодаря YOLOv8 отслеживаются только люди (класс `person`), полностью игнорируя проезжающие автомобили и статические помехи.
* **Устойчивый трекинг:** Алгоритм ByteTrack сохраняет уникальные ID пешеходов даже при кратковременном перекрытии их машинами или другими людьми.
* **Интерактивный UI Настройки (Streamlit):** Визуальный отладчик прямо в браузере позволяет в реальном времени подстраивать ширину, смещение и угол наклона коридора под любой ракурс камеры.
* **Аналитический Дашборд:** Отображение метрик в реальном времени, графики почасовой интенсивности и автоматический расчет прогнозного количества заказов на базе собранных логов.

## 🛠️ Технологический стек

* **Язык программирования:** Python 3.12+
* **Менеджер пакетов и окружения:** [uv](https://github.com/astral-sh/uv) (сверхбыстрая альтернатива pip/venv)
* **Нейросеть:** Ultralytics YOLOv8 (модель `yolov8n.pt`)
* **Трекер:** ByteTrack (`bytetrack.yaml`)
* **Компьютерное зрение:** OpenCV (обработка кадров, математика линий и визуализация)
* **Веб-интерфейс:** Streamlit + Plotly (интерактивные графики и слайдеры)
* **База данных:** SQLite (легковесное локальное хранилище логов и настроек)

## 🚀 Быстрый запуск

### 1. Клонирование репозитория и установка зависимостей

Убедитесь, что у вас установлен `uv`. Если нет, установите его одной командой: `curl -LsSf https://astral.sh/uv/install.sh | sh`.

```bash
# Установка всех зависимостей и создание виртуального окружения
uv sync

```

### 2. Запуск интерактивного дашборда настройки

Используйте веб-интерфейс, чтобы визуально настроить геометрию коридора под ракурс камеры. Благодаря кэшированию, в интерфейсе отобразится первый кадр вашего видео, на котором можно регулировать три параметра: смещение зоны, ширину коридора и угол наклона линий.

```bash
uv run streamlit run src/app.py

```

После запуска откройте в браузере адрес: `http://localhost:8501`.

### 3. Запуск аналитики видео (Инференс)

Как только коридор в браузере выставлен идеально, запустите основной процесс обработки видеопотока:

```bash
uv run src/main.py

```

*Скрипт автоматически считает выставленные в UI координаты из базы данных, откроет окно визуализации и начнет сохранять проходы людей в лог.*

## 📊 Математика детекции транзита

Вместо простой горизонтальной линии используется **динамический четырехугольный коридор**. Направление рассчитывается на основе пересечения центрального триггера объекта (`cx, cy`) относительно наклонных боковых границ:

* **Влево (IN):** Объект зафиксирован правее правой границы -> в следующем кадре его координата оказалась левее левой границы.
* **Вправо (OUT):** Объект зафиксирован левее левой границы -> в следующем кадре его координата оказалась правее правой границы.

Такой подход полностью нивелирует ложные срабатывания, если человек просто топчется на месте или разворачивается внутри зоны.
